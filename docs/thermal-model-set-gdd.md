# Термальна модель: СЕТ (GDD) для фенології винограду

> Довідка з науковими/практичними джерелами для калібрування рекомендації фаз.
> Зібрано 2026-06-19. Цифри — з джерел; інтерпольовані значення позначені окремо (без вигадок).

## Визначення СЕТ / GDD
- **СЕТ (сума ефективних температур) = GDD (Growing Degree Days)**, база **10 °C**.
- Формула: **Σ (T_сер − 10)** за дні, де T_сер > 10 °C. Один градусо-день на кожен °C понад 10.
- Виноград практично не росте нижче 10 °C → це стандартна база для *V. vinifera*.
- Старт накопичення (Пн. півкуля): зазвичай **1 березня або 1 квітня**. Шкала Вінклера —
  з 1 квітня по 31 жовтня.
- У коді: `setContribution(temp) = round1(temp − 10)` для temp ≥ 10 — це коректний GDD base-10.
  Дані T_сер — `temperature_2m_mean` з Open-Meteo (добова середня).

> **САТ** (сума активних температур) у цьому проєкті = Σ T_сер на днях ≥10 °C (повна температура,
> не T−10). САТ росте швидше і гірше відповідає фенології; тому для фаз використовуємо СЕТ.

## Сорсовані якорі (base 10 °C, старт ~1 березня)
| Стадія | СЕТ (GDD°C) | Джерело |
|---|---|---|
| Розпускання бруньок | ~75 (Шардоне, ранній) / ~87 (Каберне, пізній) | eVineyard |
| Цвітіння | ~345 (Шардоне) / ~375 (Каберне) | eVineyard |
| Верайзон | ~934 (Мерло) / ~964 (Шардоне) / ~1025 (Каберне) | ResearchGate (GFV-параметри) |
| Сезонна сума, прохолодний клімат (ранні: піно нуар, шардоне, гевюрцтрамінер) | ≤ 1390 (Регіон I Вінклера) | Winkler index |

Часові орієнтири: цвітіння — за 40–80 днів після розпускання; верайзон — за ~40–50 днів після
завʼязування ягід.

## Пропоновані пороги фаз (узгоджені з джерелами)
🟢 прямий якор · 🟡 інтерпольовано між якорями (не пряма цитата, але й не вигадка)

| СЕТ (GDD°C) | Фаза | Підстава |
|---|---|---|
| < 80 | 1 · Пробудження бруньок | 🟢 budbreak ~75–87 |
| < 320 | 2 · Старт вегетації | 🟡 між budbreak і цвітінням |
| < 345 | 3 · Перед цвітінням | 🟢 цвітіння ~345 |
| < 650 | 4 · Цвітіння → горошина | 🟡 після цвітіння до змикання |
| < 950 | 5 · Змикання ягід | 🟢 переддень верайзону (~934–1025) |
| < 1390 | 6 · Дозрівання | 🟢 верайзон ~950 → сума Регіону I ≤1390 |
| ≥ 1390 | 7 · Осіння підготовка | 🟢 понад Регіон I |

## Застереження (важливо)
- Значення залежать від **сорту** (ранній/пізній), **дати старту** накопичення та регіону.
- **Юпітер** — дуже ранній/морозостійкий → цвітіння ймовірно на нижньому краю (~300–345 GDD)
  або раніше. Локальна калібрація за власними спостереженнями має пріоритет.
- Верайзонні 934–1025 — для конкретних сортів (Каберне/Мерло/Шардоне); для інших є розкид.
- Якорі (budbreak, цвітіння, верайзон, Регіон I) — **сорсовані**; пороги фаз 2 і 4 —
  **інтерпольовані** між якорями.

## Стан у коді
- `getRecommendedPhaseId(setGdd)` у `app.js` приймає **СЕТ** (не САТ).
- **Поточні пороги в коді:** 60 / 150 / 340 / 550 / 850 / 1150 (перша СЕТ-ітерація, орієнтовні).
- **Сорсово-узгоджена пропозиція (до застосування):** 80 / 320 / 345 / 650 / 950 / 1390.
- Калібрувати в ОДНОМУ місці — функція `getRecommendedPhaseId`.

## Як калібрувати локально
Коли у вас фактично настає стадія (напр. цвітіння Юпітера) — занотуйте поточний СЕТ° із
застосунку і підставте як поріг відповідної фази. Локальні дані завжди точніші за літературні
середні.
