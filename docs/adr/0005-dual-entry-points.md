# Дві точки входу: index.html (повна) та index_clean.html (полегшена)

- Статус: Погоджено
- Дата: 2026-06-18
- Пов'язані ADR: [0001](0001-single-file-vanilla-spa.md)

## Контекст
Цільова аудиторія включає користувачів зі слабким мобільним інтернетом у сільській
місцевості. Повна версія містить важку аналітику, графіки та AI-функції. Потрібен варіант із
меншою вагою та швидшим завантаженням, але з ідентичною логікою роботи з даними (CRUD,
LocalStorage, калькулятори).

## Рішення
Підтримуються два самодостатні файли: `index.html` — повна версія (з аналітикою та AI),
де спочатку розробляються й тестуються всі нові фічі; `index_clean.html` — полегшена версія,
що вручну підтримується в актуальному стані з тією самою логікою обробки даних. Обидва файли
використовують спільні ключі `localStorage`, тож дані сумісні між версіями.

## Альтернативи
- Один файл із перемикачем «lite-режиму» через прапорець — відкинуто наразі: не зменшує
  початкову вагу завантаження.
- Збірка двох артефактів з єдиного джерела — відкинуто: суперечить рішенню «без збірки»
  ([0001](0001-single-file-vanilla-spa.md)).

## Наслідки

### Переваги
- Швидке завантаження полегшеної версії для слабкого зв'язку.
- Сумісність даних завдяки спільним ключам `localStorage`.

### Недоліки / компроміси
- Дублювання коду: будь-яка зміна логіки потребує ручної синхронізації двох файлів — головне
  джерело ризику розсинхрону та регресій.
- Подвоєний обсяг рев'ю та тестування.

### Подальші дії
- Будь-яку зміну спільної логіки застосовувати до обох файлів в одному коміті.
- Розглянути генерацію `index_clean.html` зі спільного джерела, якщо дублювання стане надто
  дорогим (це переглянуло б [0001](0001-single-file-vanilla-spa.md)).
