# Сторонні залежності через CDN без вендорингу

- Статус: Погоджено
- Дата: 2026-06-18
- Пов'язані ADR: [0001](0001-single-file-vanilla-spa.md)

## Контекст
Застосунку потрібні: утилітарні стилі (Tailwind), графіки (Chart.js), коректне відображення
емодзі на старих пристроях (twemoji) та конвертація HEIC-фото (heic2any). Оскільки збірки
немає ([0001](0001-single-file-vanilla-spa.md)), немає й менеджера пакетів для встановлення
та бандлингу залежностей.

## Рішення
JS-бібліотеки підключаються рантайм-тегами `<script>`/CDN із закріпленими версіями:
- `cdn.jsdelivr.net/npm/chart.js@4.4.6` — Chart.js;
- `cdn.jsdelivr.net/npm/twemoji@14.0.2` — twemoji;
- `cdn.jsdelivr.net/npm/heic2any@0.0.4` — конвертація HEIC.

Залежності не вендоряться в репозиторій.

> **Оновлення (O7, 2026-06-18):** Tailwind більше НЕ через Play CDN. Стилі генеруються
> Tailwind CLI (`npm run build:css`) у зібраний `styles.css`, який **комітиться** в репозиторій
> і підключається локально `<link rel="stylesheet" href="./styles.css">`. Причини: Play CDN не
> призначений для production (JIT через `eval` → блокував CSP, гірша продуктивність). Тепер
> рантайм лишається без бандлера, дворівневий деплой (Vercel + GitHub Pages) і офлайн працюють
> без кроку збірки на хостингу, а `eval` усунено — що розблокувало CSP ([0003](0003-client-side-gemini-key.md)).
> Компроміс: `styles.css` треба регенерувати (`npm run build:css`) при зміні класів.

## Альтернативи
- Локальне вендорування файлів бібліотек — відкинуто: збільшує репозиторій і ручне оновлення.
- npm + bundler — відкинуто: суперечить рішенню «без збірки» ([0001](0001-single-file-vanilla-spa.md)).

## Наслідки

### Переваги
- Мінімум обслуговування: нема кроку встановлення чи збірки.
- Кешування CDN та швидкий старт розробки.

### Недоліки / компроміси
- Рантайм-залежність від доступності CDN: офлайн і за збою CDN частина функціоналу ламається.
- Tailwind через CDN (JIT у браузері) не рекомендований для production через продуктивність
  і відсутність очищення невикористаних класів.
- Незакріплені версії (`chart.js`, `heic2any` без тега версії) — ризик ламких оновлень.

### Подальші дії
- Закріпити версії всіх CDN-залежностей явними тегами.
- Розглянути збірку Tailwind у статичний CSS для production (це частково переглянуло б
  [0001](0001-single-file-vanilla-spa.md)).
