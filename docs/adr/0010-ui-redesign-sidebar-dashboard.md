# Редизайн UI: sidebar-навігація, Dashboard, design-система

- Статус: Погоджено
- Дата: 2026-06-19
- Пов'язані ADR: [0001](0001-single-file-vanilla-spa.md), [0007](0007-cdn-dependencies.md), [0008](0008-pwa-offline-service-worker.md)

## Контекст
Початковий інтерфейс мав перевантажену горизонтальну top-bar навігацію (8 вкладок), не мав
стартового зведення (Dashboard) і непослідовну візуальну мову (emoji-іконки, різні відступи).
Потрібен сучасніший, структурованіший UX. Вхідний бриф був написаний під React/Tailwind —
адаптовано під фактичний стек (vanilla single-file, зібраний Tailwind).

## Рішення
Реалізовано редизайн у 5 спринтів (тільки `index.html`/`app.js`; лайт `index_clean.html` поза скоупом):
- **Оболонка-shell:** ліва **sidebar** (desktop, темно-зелена, секції «Головне»/«Знання») замість
  горизонтального nav; на mobile (≤768px) — **bottom-nav** + висувна **sidebar-шухляда**
  (гамбургер + backdrop), щоб усі розділи були доступні.
- **Dashboard «Огляд»** як стартовий екран: 4 stat-картки (САТ, до наступної фази, сорти+кущі,
  активні задачі), таймлайн 7 фаз (за `getRecommendedPhaseId(totalSAT)`), картка загроз поточної
  фази (severity-точки), чекліст операційних задач фази з прогрес-баром. Дані — реальні
  (`renderDashboard()`).
- **Design-система:** CSS-змінні палітри, шрифт **Golos Text** (кирилиця), єдині радіуси/відступи.
- **Іконки:** **Lucide** (UMD з jsdelivr, запінено) у навігації та заголовках секцій;
  семантичні emoji в даних (⚠️ попередження, 💡 поради, статус-точки) свідомо збережено —
  twemoji рендерить їх однаково.
- **Quick Log FAB:** плаваюча кнопка на всіх екранах → модалка швидкого запису в журнал.

Навігація і взаємодія працюють через делегування ([0009](0009-event-delegation-csp-hardening.md)).

## Альтернативи
- React/SvelteKit-переписування (як у брифі) — відкинуто: суперечить vanilla single-file
  ([0001](0001-single-file-vanilla-spa.md)); надмірно для проекту.
- Повне злиття 8 вкладок у 3 розділи — відкладено: ризиковане перекомпонування контенту;
  залишено всі розділи доступними з нової навігації.
- Повна заміна всіх emoji на Lucide — відкинуто: emoji в даних семантичні; замінено лише UI-chrome.

## Наслідки

### Переваги
- Зрозуміла точка входу (Dashboard), чистіша навігація, сучасніший вигляд.
- Мобільний UX: усі розділи доступні (шухляда + bottom-nav).
- Послідовна візуальна мова (токени, Golos Text, Lucide).

### Недоліки / компроміси
- `index_clean.html` (лайт) лишилась зі старим UI — розбіжність версій зросла ([0005](0005-dual-entry-points.md)).
- Ще одна рантайм-CDN-залежність (Lucide) ([0007](0007-cdn-dependencies.md)).
- Нові класи Tailwind вимагають `npm run build:css`.

### Подальші дії
- Тримати нові класи цілими літералами (для purge) і ребілдити `styles.css`.
- За потреби — перенести редизайн і на лайт-версію або згенерувати її зі спільного джерела.
- Lucide-іконки в динамічному контенті — викликати `refreshLucide()` після рендеру.
